# Meteo — почасовая погода в стиле Xiaomi

Это исходный Android-проект, а не готовый APK. В интерфейсе есть крупная текущая температура, ощущается как, ветер и влажность, а также горизонтальная лента на 24 часа с температурой, скоростью ветра и вероятностью осадков. Источник данных — Open-Meteo, без API-ключа. Город можно искать по названию; по умолчанию Киев.

## Как получить APK только с телефона

1. Скачай ZIP проекта и распакуй его.
2. Создай репозиторий на GitHub в браузере телефона.
3. Загрузи в репозиторий содержимое папки проекта (не сам ZIP).
4. Открой вкладку **Actions** и запусти workflow **Build Android APK** (или он запустится после загрузки в ветку `main`).
5. Открой завершившийся запуск, найди раздел **Artifacts** и скачай `Meteo-debug-apk`.
6. Распакуй скачанный архив — внутри будет `app-debug.apk`. Установи его на Samsung. Если Android спросит разрешение на установку из этого источника, разреши его для браузера/файлового менеджера.

## Важно
- Здесь нет готового APK: его должен собрать GitHub Actions.
- Сборка в облаке не проверена из этой среды; если GitHub покажет ошибку, пришли скриншот/текст ошибки.
- Приложение пока не запрашивает GPS автоматически: город выбирается поиском по названию.
- Это самостоятельный прототип с похожей логикой и визуальным настроением, не точная копия фирменного приложения Xiaomi.
